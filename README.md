# Project-1---Roulette-Game
My first Python program. A simple terminal-based Russian Roulette game that uses randomization, input validation, and recursion to handle game logic.
Built as a hands-on introduction to Python fundamentals — conditionals, loops, functions, and user input — as a stepping stone toward applied work in environmental science, geospatial analysis, and data science.

Run it:
python roulette.py
